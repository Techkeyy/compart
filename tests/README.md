# Historical lifecycle runners

The JavaScript files in this directory exercise the retired supplier-quote
prototype and previous program ID. They are retained as historical engineering
evidence, are not wired into `npm run verify`, and must not be cited as proof of
the current group-fund deployment.

Current deterministic program tests live in
`programs/compartido-market/src/lib.rs`. Current verification and known limits
are recorded in `AUDIT_REPORT.md`.
